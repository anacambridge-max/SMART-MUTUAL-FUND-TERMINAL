# Smart Mutual Fund Terminal

Web-app preparation for a daily mutual-fund opportunity engine.

## Engine goals
- Daily NSE index and sector capture with one row per trading date.
- AMFI scheme-code-first NAV matching.
- Fund-level weighted sector exposure instead of single-index proxy scoring.
- NAV trend, drawdown, momentum and relative-strength filters.
- Automated dashboard refresh during market hours.
- Tactical labels: Strong Buy Today, Buy on Dip, Accumulate, SIP, Wait, Avoid Today.

The initial repository is being populated from the Smart MF Decision Terminal ZIP and upgraded for the next dashboard build.
